本分支在經典版骰子引擎(v52)之上,實作完整的**回合制戰鬥推演**:雙陣營角色卡、技能原語系統、攻擊對拼、受傷表、眩暈/處決/自動勝利/持續效果——規則還原自《烈海王幻想入》與《炎火村獵人》的戰鬥系統。

> main 分支 = 經典安科連鎖版(穩定);本分支 = 戰鬥版(積極開發)。兩版並行,merge 時程待定。

## 使用

- 下載 [`index_classic.html`](index_classic.html),雙擊即用(單檔、離線、無任何網路依賴)
- 戰鬥面板 → **⚔️ 開戰**(自動模擬整場)/** 🃏 卡組工房**(角色卡編輯與管理)
- 預設對決:烈海王(Atk 216/Hp 17)vs 紅美鈴(Atk 225/Hp 18)

## 戰鬥規則(標準層——所有角色共用)

1. **攻擊對拼**:雙方 Atk(含技能修正)+ 1d100 比大小——攻擊骰**無**大成功/大失敗(88:797F)
2. **免擲判定**:數學必然時免骰直接判定——我方上限追不上對手 ➔ 自動失敗;我方下限已超過 ➔ 自動命中(88:635F)
3. **平手裁定**:對拼同值 ➔ 雙方各擲武藝 1d100,勝者攻擊成立(88:634F/639F)
4. **受傷表 1d10**:敗方擲表定傷害檔位——1 迴避/2-3 小傷 1/4-5 中傷 2/6-7 大傷 3/8-9 特大 4/10 極端
5. **第 10 行**:1d2 ➔ 大成功——完全防禦,並**對攻方骰受傷反擊**(88:F1418 起;接連大成功反擊無加成);大失敗——原作為**每戰自訂專屬大失敗表**(×2 傷害行+戰鬥不能行+敘事事件,88:233F/456F、225-236F T8 實演),引擎簡化為再擲同一表全行 ×2
6. **眩暈**:命中後特殊攻擊判定 1d100——原作 21033:886F「**10-30** 不眩/31-65 眩 1 回合/66-100 眩 2 回合」(1-9 原文未定義,併入不眩);**未中累計 -10 判定難度、眩暈成功即重置**;眩暈方=跳回合(對手攻擊自動成立+受傷結算)——「戰鬥自動失敗」是束縛(88:636F)語義,走 special 的束縛效果
7. **處決**:敵 HP ≤ 上限 20% ➔ 直接擊殺(74:8130F 榮耀處決);**多段血條依總和生命判定+只能最後一段使用+判定區間 +10**
8. **自動勝利**(88:6117F The World 兩段):**發動即本回合自動勝利+傷害必中**;對 Atk < 門檻的對手直接判定戰鬥結束
9. 50 回合兜底平局——**引擎自創 loopSafety**(原作無固定回合數,靠差值>100 即決+爆發在 5~11 回合收束;原作平局=明文「平局 无人胜利」結算,F1821/F2632)——可用戰鬥配置的回合上限覆寫

## 卡面層原語(角色差異 = 原語組合)

**技能欄位**(工房可編輯):CT 冷卻/Atk±/傷害×倍率/骰式傷害(`2+1d5`)/破解門檻/必中(直接傷害)/回復/持續 T(Atk± 持續)/一場一次/眩暈/護盾+/蓄力 T/**特殊判定**(B-11 DSL)/技能類別 cat(破解分檔)/破解檔 counterCat/破解連動 counterRip/屬性(繞過消力)/**自動HP%**(B-5 閾值自動技,俠客行式)/**姿態切換**(B-9,閃避 ×1.8);僅 JSON/電池可設:HP 消耗/處決門檻/自動勝利門檻/CT 清 0/真實傷害/條件解鎖

**角色欄位**(工房可編輯):名稱/Atk/Hp/**血條段**(均勻段=卡面 hp;逗號串=每段獨立上限,如「20,10,5,5,1」)/支援位/regen/表位移(受傷骰 ±N)/表+N(每行傷害 +N)/消力半·消力-N·穿透門檻(減傷三件套 B-1)/戰意門檻·戰意檢定(A-6)/**🩹 個人受傷表**(B-2 DSL)/**復活**(B-5,數值或骰式)·復活次數;另有**戰鬥配置**:模式(HP/勝點制 B-12)/回合上限/HP 鎖定線/離場線(A-10)

## 🃏 角色卡工房

戰鬥面板 →「🃏 卡組工房」開啟全屏視圖:

- 雙欄完整卡編輯(玩家/敵人,全部原語欄位)
