本分支在經典版骰子引擎(v52)之上,實作完整的**回合制戰鬥推演**:雙陣營角色卡、技能原語系統、攻擊對拼、受傷表、眩暈/處決/自動勝利/持續效果——規則還原自《烈海王幻想入》與《炎火村獵人》的戰鬥系統。

> main 分支 = 經典安科連鎖版(穩定);本分支 = 戰鬥版(積極開發)。兩版並行,merge 時程待定。

## 使用

- 下載 [`index_classic.html`](index_classic.html),雙擊即用(單檔、離線、無任何網路依賴)
- 戰鬥面板 → **⚔️ 開戰**(自動模擬整場)/** 🃏 卡組工房**(角色卡編輯與管理)
- 預設對決:烈海王(Atk 216/Hp 17)vs 紅美鈴(Atk 225/Hp 18)

## 戰鬥規則(標準層——所有角色共用)

1. **攻擊對拼**:雙方 Atk(含技能修正)+ 1d100 比大小——攻擊骰**無**大成功/大失敗(88:797F)
2. **免擲判定**:數學必然時免骰直接判定——我方上限追不上對手 ➔ 自動失敗;我方下限已超過 ➔ 自動命中(88:635F)
3. **平手裁定**:對拼同值 ➔ 雙方各擲武藝 1d100,勝者攻擊成立(88:634F/639F)
4. **受傷表 1d10**:敗方擲表定傷害檔位——1 迴避/2-3 小傷 1/4-5 中傷 2/6-7 大傷 3/8-9 特大 4/10 極端
5. **第 10 行**:1d2 ➔ 大成功(完全防禦+反擊 2)或大失敗(再擲受傷表、全行 ×2)(88:635F)
6. **眩暈**:命中後特殊攻擊判定 1d100——1-30 不眩/31-65 眩 1 回合/66-100 眩 2 回合(眩暈中方該回合自動敗)
7. **處決**:敵 HP ≤ 上限 20% ➔ 直接擊殺(74:8130F 榮耀處決)
8. **自動勝利**:對手 Atk < 門檻 ➔ 直接判定戰鬥結束(88:6117F The World)
9. 50 回合兜底平局(原作靠免擲即決收束,5~11 回合)

## 卡面層原語(角色差異 = 原語組合)

**技能欄位**(卡組工房可編輯):CT 冷卻/Atk±/傷害×倍率/骰式傷害(`2+1d5`)/破解門檻/必中(直接傷害)/回復/持續 T(Atk± 持續)/一場一次/眩暈/護盾+/CT 清 0/自動勝利門檻/處決門檻/真實傷害(無視破解)

**角色欄位**:名稱/Atk/Hp/**血條段**(多段 BOSS,擊破後滿血續戰)/regen(每回合回復)/表位移(受傷骰 ±N)/表+N(每行傷害 +N)

## 🃏 角色卡工房

戰鬥面板 →「🃏 卡組工房」開啟全屏視圖:

- 雙欄完整卡編輯(玩家/敵人,全部原語欄位)
- **卡組多槽保存**(localStorage,命名存取)
- 匯出 JSON(剪貼簿/下載檔案)+ 匯入(貼上,結構驗證)
- 重置預設(烈幻入雙卡)

## 多對手(2v1)

合併單卡:將多角色的總 Atk/Hp 填入單卡(原作九十九姐妹 2v1 式)。真陣列多對手(每回合選目標)在 roadmap。
